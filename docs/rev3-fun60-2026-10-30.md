# FUN60 추가 측정 — 2026-10-30

이 문서는 당시 측정/계산 기준을 보존한 기록입니다. 이후 기본 표시를 바꾼 내용은 [기준 장비 맞춤 보정 기록](rev3-reference-calibration-2026-10-30.md)에 있습니다.

[앞선 Rev3 조사 기록](rev3-investigation-2026-10-29.md)에 이어 FUN60 유선 측정을 안내한 뒤 사용자가 제공한 결과다. 기본 화면의 요청 기준 수식과 수신 먼저 순서를 사용했다. 측정 코드·계산식·화면은 이번 기록 추가에서 변경하지 않았다.

## 파일에서 확인한 조건

- 원본: `rakka-rev3-2026-10-30.csv`, [보관 CSV](experiments/rev3-2026-10-30/fun60-wired.csv).
- 50회 모두 성공, 실패·OUT 재전송 없음.
- `revision=rev3`, `timing_basis=out_request`, `transfer_order=prearmed`.
- 유지시간 20ms, 응답 명령/값 모두 2/20.
- 측정 간격 50ms·예열 5회를 안내했으나 이 CSV에는 간격/예열 횟수와 장치 이름·측정 키·포트 정보가 없다. CSV만으로 해당 조건을 재확인할 수는 없다.

단위는 ms. Keyup은 요청 유지시간 20ms를 뺀 값이다. 실제 테스터 접점 시각을 측정한 결과는 아니다.

이번 50회에서는 앞선 GMK70의 47.1ms Keyup 튐이나 입력 시간 초과가 재현되지 않았다. 한 번의 결과로 FUN60에는 그런 현상이 없다고 일반화하지 않는다.

## USB·입력 시각

| 지표 | 평균 | 최소 | 최대 |
| --- | ---: | ---: | ---: |
| OUT 요청→OUT 완료 | 11.896 | 8.300 | 16.800 |
| IN 완료−OUT 완료 | −0.018 | −0.100 | 0.000 |
| 양쪽 통신 완료까지 | 11.896 | 8.300 | 16.800 |
| IN 기준 Keydown | −6.754 | −8.300 | −6.100 |
| IN 기준 Keyup | −7.554 | −9.100 | −6.800 |
| Keydown 이벤트→처리 | 0.256 | 0.200 | 0.700 |
| Keyup 이벤트→처리 | 0.142 | 0.000 | 0.300 |

50회 모두 Keydown이 OUT 완료와 IN 완료보다 먼저 관측됐다. IN 기준 Keydown/Keyup 값도 모두 음수였다. 따라서 IN 완료나 OUT 완료를 그대로 접점 누름 시각이라고 확정할 수 없다. 수신 먼저 순서에서는 9회가 IN 선완료였고 그 시각과 음수 구간을 보존했다.

## 요청 기준 값의 변동

OUT 요청→완료 소요와 요청 기준 Keydown의 Pearson 상관계수는 0.993836, Keyup은 0.995004였다. 모집단 표준편차는 요청 기준 Keydown 2.577ms / Keyup 2.475ms였고, IN 기준은 각각 0.280ms / 0.259ms였다.

관측값은 `요청 기준 = IN 기준 + (IN 완료−OUT 요청)` 관계를 갖는다. 상관은 이 대수적 관계와 공통 기준점을 포함하므로 독립적인 인과 검증이 아니다. 다만 이번 데이터에서 큰 요청 기준 변동이 USB 완료 관측 구간과 함께 움직이며, 그 변동을 모두 키보드 지연으로 해석하기 어렵다는 근거다. 이 구간에는 호스트 API 대기와 완료 콜백 실행 시각의 영향도 포함된다.

예를 들어 46회차는 OUT 소요 16.2ms, 요청 기준 Keydown 10.1ms였지만 IN 기준 Keydown은 −6.1ms였다. 평균 5.124ms를 FUN60 자체의 절대 지연이나 검증된 보정값으로 취급하지 않는다.

## 앞선 GMK70과 같은 기준으로 환산

이전 접점 순서 비교의 수신 먼저 35회만 가져와 새 기본 수식 `Kd−T0`, `Ku−T0−H`로 재계산했다. 이전 화면의 중간점 값과 비교하지 않았다.

| 요청 기준 평균 | GMK70 수신 먼저 35회 | FUN60 이번 50회 |
| --- | ---: | ---: |
| Keydown | 12.023ms | 5.124ms |
| Keyup | 11.826ms | 4.324ms |

출처: [GMK70 접점 비교 원본](experiments/rev3-2026-10-29/contact-order-comparison.csv)의 `prearmed` 성공 행. 두 실행의 유지시간·수신 순서·계산 기준은 같지만 서로 다른 실행이며 측정 키·포트 등을 같은 조건으로 통제했다는 기록은 없다. 표는 기준을 맞춘 관측 비교이지, 차이가 전부 키보드 자체에서 발생했다는 증명이 아니다.

## 판단과 보존

이번에는 50회를 끝까지 수집했고 요청 기준 음수나 수십 ms급 튐이 없었다. 원본 IN 기준 음수는 여전히 남았다. 기준점을 요청 시각으로 옮긴 것은 미보정 경과시간을 표시하는 변경이며 절대 정확도 검증은 아니다. 테스터 접점 작동 지연 D는 여전히 미확정이다. 이 자료의 평균·최솟값이나 OUT 구간만으로 임의의 고정 D를 정하지 않는다.

원본 파일은 바이트 변경 없이 복사했고 [manifest.json](experiments/rev3-2026-10-30/manifest.json)에 원래 이름·크기·SHA-256을 남겼다. 기본 결과, IN 기준 결과와 USB 구간을 원본 시각으로 재계산해 50행 모두 일치함을 확인했다. 이번 작업은 기록 추가이며 새 보정식이나 추가 UI는 넣지 않았다.
