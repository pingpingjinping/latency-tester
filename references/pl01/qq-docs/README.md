**원문 제목:** PL01 延迟测试器技术文档 (PL01 레이턴시 테스터 기술문서)

**확보:** 사용자가 제공한 화면 캡처 5장, 2026-10-15. 문서 전체 수록 여부는 확인되지 않았습니다.

## 캡처별 목차

1. 제품 소개, 본체/프로브 사진, 측정 원리
2. PC → PL01 누름 명령·확인 응답 → 실제 입력 이벤트 수신의 처리 흐름도
3. 지원 키보드, USB-C 연결법, 웹 측정 순서의 앞부분
4. 프로브 접점 연결, 측정 파라미터 정의, 정확도·크기·무게
5. 구성품과 FAQ: 0ms 현상 및 브라우저 오류·통신 불안정

## 핵심 내용 한국어 요약 (캡처 원문 기준)

- **원리:** 프로브 연결·차단으로 스위치 누름/뗌을 시뮬레이션하고, 명령 전송 시각과 PC가 입력 이벤트를 인식한 시각을 비교합니다. 도식에는 200ms 내 키 이벤트가 없으면 무효로 처리하는 과정도 나옵니다.
- **지원:** 기계식 키보드의 유선·블루투스·2.4GHz 연결. 납땜 키보드는 측정 대상 키의 PCB 접점에 프로브 연결이 필요합니다.
- **순서:** 프로브 모듈 조립 → USB-C로 PC 연결 → https://pl.ptgstudio.com 접속 → 측정 키 선택 → 두 프로브를 해당 키 스위치의 접점에 연결 → 매개변수 설정 → 측정 시작.
- **유지 시간:** 가상 누름을 지속하는 시간(ms).
- **측정 간격:** 전체 누름+뗌 샘플과 다음 샘플 사이의 간격(ms).
- **샘플 횟수:** 누름+뗌 한 세트를 1개 샘플로 셉니다.
- **측정 횟수:** 완전한 측정 세트 전체를 반복하는 횟수입니다.
- **기재 사양:** 정확도 ±1~2ms, 35 × 15 × 7.35mm, 약 5g. 이는 제품 문서의 주장이지 별도 검증 결과가 아닙니다.
- **0ms만 표시:** 프로브 접촉 위치·대상 키가 맞는지 점검합니다.
- **`keydownLatency` 오류:** 문서에서는 불안정한 USB 통신/USB 허브/PC 신호 환경 등을 가능 원인으로 설명하며 PC 직결·포트 변경을 권장합니다.
